# 2023 Q4 冻结模型时间外验证

完成日期：2026-09-22。固定研究协议R1.0，零重新训练。完整执行和独立核验通过。

## 结论

current_lr捕获 **40/86** 个机会事件（46.51%），SMART规则捕获 **35/86**（40.70%）；差值为 **+5.81个百分点**，两者均产生1247条告警。

本季度有86个机会事件，少于事先规定的100事件解释门槛。因此只报告描述性差异，不发布确认性区间，**未达到预设增益证据要求**。这不能推出两种方法等效，也不构成模型部署或维护收益证据。已知结局AP与提前量是预定次指标，不能替代主比较的事件量要求。

## 数据与固定策略

- Backblaze官方Q4 ZIP：92个日期文件，24,790,999条源记录，主型号ST4000DM000共1,295,929条设备日。
- 评分期10-01—12-24；主事件10-08—12-25；结局截止12-31。继承Q1—Q3既往failure与前13日观测，新设备达到历史门槛可进入。
- 共1,216,041个合格评分设备日、15,976台至少有一次合格评分的设备。每日容量ceil(N/1000)，两方法各自七日冷却，季度首日空冷却。
- 冻结Q1/Q2的16列current_lr参数，只与SMART5/187/188/197/198当前非零规则比较。没有换模型、重新拟合或按Q4结果选窗口/阈值。

|---|---:|---:|
| 命中机会事件 | 40/86 | 35/86 |
| 事件召回 | 46.51% | 40.70% |
| 告警条数 | 1247 | 1247 |

| 命中事件提前量Q25 / 中位 / Q75（日） | 2 / 3 / 6 | 1 / 2 / 4.5 |

| 后续重复告警 | 1042 | 858 |
| 段外事件关联告警 | 3 | 2 |

逐告警上下界把未知标签分别置于最不利/最有利情形，**不是置信区间**。AP使用全部已知结局评分行（1,184,357行，609个正标签设备日），不是只在已选告警内计算。一个故障事件可对应多个正标签日，609个正标签日不能替代86个机会事件。

两方法共同命中29个事件，只有LR命中11个，只有SMART命中6个，两者均未命中40个。LR的告警更集中于较少设备，并有更多重复提醒；较高的排序指标不能直接换算成检查成本下降。提前量分位仅针对各自命中的事件，比较时也受命中集合差异影响。

## 质量门与解释门

共同评分行unknown为31,684/1,216,041（2.61%），低于固定20%质量门。LR相对SMART的unknown告警比例增加0.88个百分点，未超过2个百分点限制。

2000次固定设备级配对重抽全部有效；仍因86<100而不发布确认性区间，不事后降低门槛或延长季度凑事件。百万设备日包含同一设备的大量重复观测，不能视为百万个独立故障事件。

## 执行与核查

原始ZIP和每日CSV的身份、日期、完整性及面板值已核对；跨季身份、全部既往failure、16列特征、冻结分数、每日容量/冷却名单、标签和指标由独立计算核验。选择库先关闭并封存，随后打开结局评价，选择SHA前后一致。独立进程重新核验通过后才发布完成标记。

记录到1条SMART5/9/187下降，原值保留并收入独立诊断账本，不删除设备或改分数。首次计算曾因官方包内`.DS_Store`在CSV打开前停止（候选0行）；目录识别修正后复用同一下载，原失败记录与修正前后的两份运行批准记录均保留在本地。没有根据Q4标签或成绩修改方法。

完成标记绑定98份产物；记录的监督峰值RSS约1074.0MiB，计算链约34.0分钟；清理状态complete。该时间不含先前下载。实际数值见[结构化汇总](data/q4_summary.json)。

## 范围与证据

这是历史数据上模型冻结后的时间外留出评价，设备可能与训练期重叠；不称全新设备泛化或现场前瞻试验。公开failure为运营标记，不等于维修确认的机械失效；退出观察保留unknown。设备重抽不覆盖共同日历冲击，不能推及所有厂商/型号。Q3仍是经历开发选择的探索性结果，不能与Q4合并成新的确认性分母。
